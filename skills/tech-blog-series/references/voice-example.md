# Voice signature example: a founder-engineer's technical blog

This was derived with `technical-content-writer`'s voice-extraction protocol from two essay posts
and one walkthrough post on the author's own blog. Re-derive a signature from the live posts for
every new author. This file is a format example.

```
VOICE SIGNATURE
author:      senior engineer and founder; builds production ML systems; teaches peer to peer
person:      "I" for decisions and opinions, "we" for team work, never a royal "we"
registers:   essay (median ~10 words per sentence, short declaratives, some fragments) for ideas;
             walkthrough (longer sentences, numbers, mechanism) for systems
cadence:     short sentence after a long one; paragraphs 1–5 sentences, deliberately uneven
devices:     colon as a reveal; arrows (→) for pipelines in prose; one concrete number per claim;
             analogies from everyday life; earned admissions ("I'd still bet on it")
contrast:    "X, not Y" at most twice per post
bold:        at most one standalone sentence per section, stating a rule or fact
contractions: yes (it's, don't, can't)
opinions:    one first-person view per H2 ("I think…", "I now check…")
headings:    thesis sentences in sentence case; reading the H2s alone gives the argument
never:       exclamation marks, an opening question, semicolons, em dashes, emoji, mid-sentence
             bold, bold-label-colon lists, "In this post", summary recaps, aphorism closers
openings:    a concrete scene, then the hard physical fact, then the person, then the scale
endings:     a decision rule the reader can apply; one sentence pointing to the next post
```
